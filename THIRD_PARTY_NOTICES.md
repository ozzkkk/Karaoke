## Audio fingerprint algorithm

The Shazam-compatible fingerprint format and peak-selection approach are adapted from `ShazamSignature.kt` in the supplied Prism project. That source file attributes the underlying algorithm to SongRec by Marin M. (https://github.com/marin-m/SongRec) and identifies it as GPL-3.0. The browser implementation is a JavaScript port of that approach.
